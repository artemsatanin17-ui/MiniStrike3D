# Mini Strike 3D — Android APK wrapper

Это Android-проект, который упаковывает текущую HTML-версию игры в полноэкранное приложение WebView.

## Важно
- Для загрузки Three.js с jsDelivr требуется интернет.
- Это первая APK-оболочка: она не превращает HTML-игру в нативный 3D-движок.
- APK собирается через GitHub Actions: загрузите содержимое проекта в свой GitHub-репозиторий, откройте вкладку Actions и запустите `Build Mini Strike APK` через `Run workflow`. После успешной сборки скачайте artifact `Mini-Strike-3D-debug-APK` и распакуйте ZIP — внутри будет `app-debug.apk`.
- Перед публикацией стоит создать собственную подписанную release-сборку и протестировать игру на устройстве.
